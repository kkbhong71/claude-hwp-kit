# 클로드 한글(HWP) 문서 키트

Claude에게 **"○○ 계획서를 한글 문서로 만들어 줘"** 라고 말하면
내용 작성부터 **꾸며진 한글(.hwp) 파일 + PDF** 저장까지 한 번에 해 주는 키트입니다.
학교 업무 문서(운영 계획서, 운영 방안, 보고서, 행사 계획 등)에 맞춰져 있습니다.

![결과물 예시](예시/미리보기.png)

> 위 그림은 "중학교 영어 기초학력 운영 방안을 10쪽 이내로 작성해 줘" 요청으로 만든 문서의 첫 쪽입니다.
> 전체 결과물: [예시/영어_기초학력_운영방안.pdf](예시/영어_기초학력_운영방안.pdf)

---

## 준비물

| 준비물 | 비고 |
|---|---|
| Windows 10 / 11 PC | Mac은 사용 불가 |
| 한컴오피스 한글 | 학교 PC에는 대부분 설치되어 있음 |
| Claude 유료 요금제 (Pro 이상) + [Claude 데스크톱 앱](https://claude.ai/download) | **Code 탭**을 사용합니다 |
| Python | 없으면 설치 중에 자동으로 설치할 수 있습니다 |

**Windows MCP 등 별도의 MCP는 필요 없습니다.** Claude 앱의 Code 탭이 PC에서 직접 한글을 조작합니다.

---

## 설치 (3가지 중 하나)

### 방법 A. 파일로 받기
1. 이 페이지 오른쪽 위 초록색 **Code** 버튼 → **Download ZIP** (또는 전달받은 `claude-hwp-kit.zip`)
2. ZIP 파일 **압축 풀기**
3. 폴더 안의 **`설치하기.bat` 더블클릭** → 초록색 OK가 6번 나오면 끝

### 방법 B. Claude에게 설치 맡기기 (가장 쉬움)
Claude 데스크톱 앱 → **Code** 탭에서 아래처럼 입력하세요.

```
github.com/<계정이름>/claude-hwp-kit 키트를 내려받아서 install.ps1로 설치해 줘
```

### 방법 C. git 사용자
```bash
git clone https://github.com/<계정이름>/claude-hwp-kit.git
cd claude-hwp-kit
powershell -ExecutionPolicy Bypass -File install.ps1
```

설치가 하는 일: 한글·Python 확인 → `pyhwpx` 설치 → Claude 스킬을 `%USERPROFILE%\.claude\skills\school-hwp-docs` 에 복사 → `문서\HWP자동화` 작업 폴더와 바탕 화면 바로가기 생성 → 시험 변환

---

## 사용하기

1. Claude 데스크톱 앱 → **Code** 탭 → 폴더로 **`문서\HWP자동화`** 선택
2. 요청 예시
   - `2027학년도 과학 탐구 동아리 운영 계획서를 3쪽 이내 한글 문서로 만들어 줘`
   - `중학교 수학 기초학력 보장 운영 방안을 8쪽 이내로 구체적으로 작성해 줘`
   - `방금 만든 문서에서 예산 합계를 500만 원으로 맞추고 다시 만들어 줘`
3. 완성된 `.hwp`, `.pdf` 는 `문서\HWP자동화` 폴더(바탕 화면 바로가기)에 저장됩니다.

## 직접 변환만 하고 싶을 때 (Claude 없이)

원고(.md)가 있으면 Claude 없이도 변환할 수 있습니다.

```bash
python md2hwp.py 원고.md 결과.hwp --pdf
```

| 원고 문법 | 문서 모양 |
|---|---|
| `# 제목` | 남색 제목 상자 |
| `## 1. 장 제목` | 번호 칸 + 연한 바탕 띠 |
| `### 소제목` | ■ 굵은 글씨 |
| `- 내용` | ○ 글머리표 |
| `> 내용` | ※ 참고 문구 |
| 마크다운 표 | 남색 머리행, 줄무늬, '합계' 행 강조 |
