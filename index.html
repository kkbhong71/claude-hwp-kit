설치하기

편한 방법 하나만 고르세요. 대부분 5분 안에 끝납니다.

  1. 키트를 내려받습니다. 위의 키트 내려받기 (ZIP) 버튼을 누르세요. 메신저·메일로 claude-hwp-kit.zip 파일을 받았다면 그 파일을 쓰면 됩니다.
  2. 압축을 풉니다. ZIP 파일을 마우스 오른쪽 버튼으로 누르고 모두 압축 풀기를 선택하세요.
  3. 설치하기.bat을 더블클릭합니다. 보안 경고 창이 뜨면 실행을 허용하세요. 파란 'Windows의 PC 보호' 창이면 추가 정보 → 실행을 누르면 됩니다. Python이 없으면 설치할지 물어봐요. Y를 입력하면 됩니다.
  4. 초록색 OK가 6번 나오면 끝! 바탕 화면에 HWP자동화 폴더 아이콘이 생기고, 그 안의 설치확인.hwp를 열어 보면 꾸며진 문서가 보입니다.
  1. Claude 데스크톱 앱을 열고 </> Code 화면에서 환경을 로컬로 고릅니다. 웹 브라우저의 claude.ai가 아니라 PC에 설치한 앱이어야 해요.
  2. 아래 문장을 복사해 붙여 넣고 보냅니다.
    github.com/kkbhong71/claude-hwp-kit 키트를 내려받아서 install.ps1로 설치해 줘
  3. 허용 여부를 물으면 내용을 읽고 허용을 누릅니다. Claude가 내려받기, 설치, 시험 변환까지 진행하고 결과를 알려 줍니다.
  1. 저장소를 복제합니다.
    git clone https://github.com/kkbhong71/claude-hwp-kit.git
  2. 설치 스크립트를 실행합니다.
    powershell -ExecutionPolicy Bypass -File claude-hwp-kit\install.ps1

이렇게 사용하세요

  1. Claude 데스크톱 앱 → 왼쪽 위 </> Code → 새로 만들기 → 환경 로컬 → 폴더 문서\HWP자동화를 선택합니다. 환경이 '클라우드'나 '자동'이면 '로컬'로 바꾸세요. 다음부터는 같은 방법으로 새 세션을 열면 됩니다. OneDrive 백업이 켜진 PC는 폴더 위치가 '백업 시작 > 문서 > HWP자동화'로 보여도 정상이에요.
  2. 만들고 싶은 문서를 말로 요청합니다. 문서 종류, 학년도, 분량, 꼭 넣을 내용을 함께 말하면 더 좋아요.

    요청 예시 (눌러서 복사)

    2027학년도 과학 탐구 동아리 운영 계획서를 3쪽 이내 한글 문서로 만들어 줘
    중학교 수학 기초학력 보장 운영 방안을 8쪽 이내로 구체적으로 작성해 줘
    학교 축제 운영 계획을 일정표와 역할 분담표를 넣어서 한글 문서로 만들어 줘
  3. 완성된 파일을 확인하고, 필요하면 말로 고칩니다. "3장에 표를 하나 더 넣어 줘", "2쪽으로 줄여 줘", "주 색상을 초록색으로 바꿔 줘"처럼 이어서 요청하면 됩니다.

자주 묻는 질문

설치는 됐는데, 웹(claude.ai/code)에서 '로컬 · 데스크톱 앱 전용'이라고 나와요.

웹 브라우저의 Claude는 인터넷 서버에서 동작해서 내 PC의 한글을 쓸 수 없어요. Claude 데스크톱 앱을 설치해 같은 계정으로 로그인한 뒤, 앱의 Code 화면에서 환경을 로컬, 폴더를 문서\HWP자동화로 골라 시작하세요.

Claude 채팅(Chat 탭)에서도 되나요?

아니요. 한글 프로그램을 직접 조작해야 해서 Code 탭에서만 됩니다. Chat 탭에서 요청하면 글로만 답하거나 Word 파일을 만들어요.

Mac이나 학교 크롬북에서도 쓸 수 있나요?

아니요. 한컴 한글을 자동으로 조작하는 기능이 Windows에서만 동작합니다.

설치 중에 '한글이 설치되어 있지 않습니다'라고 나와요.

한컴오피스 한글을 먼저 설치한 뒤 설치하기.bat을 다시 실행하세요.

'Python을 설치했지만 인식되지 않습니다'라고 나와요.

설치 직후에는 아직 인식이 안 될 수 있어요. PC를 다시 시작한 뒤 설치하기.bat을 한 번 더 실행하세요.

한글 '보안 승인' 창이 떠요.

프로그램이 한글 파일을 만들려고 접근하는 것이니 모두 허용을 누르면 됩니다.

Claude가 한글 문서를 안 만들고 글로만 답해요.

Code 탭인지 확인하고, 요청 끝에 "school-hwp-docs 스킬로 한글 문서로 만들어 줘"라고 덧붙여 보세요.

그 밖의 오류가 생기면 어떻게 하나요?

오류 화면을 캡처해 Claude Code에 붙여 넣고 "이 오류 해결해 줘"라고 요청하면 대부분 바로 해결됩니다. 자세한 내용은 초보자 가이드 PDF의 '문제 해결'을 참고하세요.
