# 학교 문서 HWP 만들기

교사가 요청한 업무 문서를 **마크다운 원고 → 꾸민 한글 문서(.hwp + .pdf)** 로 만든다.
변환은 이 스킬 폴더의 `scripts/md2hwp.py`가 PC의 한컴 한글을 직접 조작(pyhwpx)해서 수행한다.
원고만 잘 쓰면 디자인은 스크립트가 일관되게 입혀 주므로, 시간은 내용의 구체성에 쓰는 것이 좋다.

## 1. 준비 확인 (세션마다 처음 한 번)

```powershell
python -c "import pyhwpx, win32com.client; print('OK')"
```

- 실패하면 `python -m pip install pyhwpx pywin32` 로 설치한다.
- `python` 을 찾을 수 없다고 나오면 Python이 설치되지 않은 것이다. 사용자에게 키트의 `설치하기.bat` 실행을 안내하거나, 동의를 받고 `winget install -e --id Python.Python.3.12` 로 설치한다.
- 한컴 한글이 설치되어 있지 않으면 .hwp를 만들 수 없다. 이때는 사용자에게 알리고 Word(.docx) 등 대안을 제안한다.

## 2. 저장 위치

- 기본 작업 폴더는 탐색기에서 보이는 **"문서" 폴더 안의 `HWP자동화`** 이다. 경로는 다음으로 구한다.
  ```powershell
  Join-Path ([Environment]::GetFolderPath('MyDocuments')) 'HWP자동화'
  ```
  (OneDrive 백업이 켜진 PC는 `OneDrive\문서` 로 잡힌다. 탐색기의 "문서"와 같은 곳이라 사용자가 찾기 쉽다.)
- 사용자가 다른 폴더를 말하거나, 세션이 이미 다른 폴더에서 열려 있으면 그곳을 쓴다.
- 파일 이름은 내용을 알 수 있게 한글로 짓는다. 예: `영어_기초학력_운영방안.md` → `.hwp`, `.pdf`

## 3. 원고(.md) 작성 규칙

스크립트가 인식하는 문법과, 문서에서 어떻게 보이는지:

| 마크다운 | 한글 문서 표현 | 용도 |
|---|---|---|
| `# 제목` | 남색 상자, 흰 글씨 (한 줄 자동 맞춤) | 문서 제목, 1회만 |
| `## 1. 장 제목` | 남색 번호 칸 + 연한 바탕 띠 | 큰 장. 반드시 `숫자.` 로 시작 |
| `### 1.1 소제목` | ■ + 굵은 글씨 | 장 안의 세부 항목 |
| `- 내용` | ○ 글머리표 (내어쓰기) | 대부분의 본문 |
| `1. 내용` | 번호 문단 | 절차·순서·목표 |
| `> 내용` | ※ 회색 작은 글씨 | 예시 수치·예산 조정 등 단서 |
| 표 (`\|a\|b\|` + `\|---\|`) | 남색 머리행, 줄무늬, 열 너비 자동 | 현황·일정·예산·역할 |
| 일반 문장 | 양쪽 정렬 문단 | 꼭 필요할 때만 |

작성 요령 (학교 문서 관례를 따르면 읽는 사람이 편하다):
- 문장은 개조식으로 "~한다.", "~함." 체로 끝맺는다.
- 표의 마지막 행 첫 칸이 `합계`/`계`/`총계`/`소계`이면 자동으로 강조되므로 예산표는 이렇게 끝낸다.
- 중첩 목록(들여쓴 `-`)은 지원하지 않는다. 하위 내용은 `###` 소제목으로 나누거나 표로 정리한다.
- 굵게(`**`)·코드(`` ` ``) 표시는 변환 시 제거되므로 강조가 필요하면 소제목이나 표를 쓴다.
- 학교명·인원·금액처럼 사용자가 주지 않은 정보는 `○○`, `○명` 또는 현실적인 예시 값을 쓰고, 예시 값이면 `>` 참고 문구로 "예시이며 학교 실정에 맞게 수정"이라고 밝힌다.
- 학년도는 오늘 날짜 기준 다음 학년도(3월 시작)를 기본으로 한다. 사용자가 정하면 그대로 따른다.

계획서·운영 방안의 일반적인 장 구성 (요청에 맞게 가감):
추진 배경(목적) → 현황 및 문제점 → 운영 목표(성과 지표) → 추진 체계 → 세부 운영 내용 → 연간(월별) 일정 → 평가 및 환류 → 소요 예산 → 기대 효과

분량 감각 (이 서식 기준): 본문 약 700~900자 + 표 1~2개 ≈ 1쪽. "○쪽 이내"라는 요청이 있으면 이를 기준으로 원고 분량을 잡는다.

## 4. 변환

```powershell
$env:PYTHONIOENCODING = "utf-8"
$script = Join-Path $env:USERPROFILE '.claude\skills\school-hwp-docs\scripts\md2hwp.py'
python $script 원고.md 결과.hwp --pdf
```

- 스킬이 다른 위치에 설치되어 있으면 이 SKILL.md가 있는 폴더의 `scripts\md2hwp.py` 를 쓴다.
- `--pdf` 를 붙이면 같은 이름의 PDF도 저장된다(검토·공유용).
- 같은 이름의 .hwp가 있으면 덮어쓴다. 사용자가 직접 고친 파일일 수 있으면 먼저 확인한다.
- 한글이 백그라운드로 실행되므로 1~3분 걸릴 수 있다. 타임아웃은 넉넉히(5분 이상) 준다.
- 한글 "보안 승인" 창이 뜨면 사용자에게 **모두 허용**을 누르도록 안내한다.

## 5. 결과 확인 (꼭 눈으로 볼 것)

텍스트가 들어갔는지만으로는 모양 문제(제목 줄바꿈, 표 칸 좁음, 빈 쪽)를 알 수 없으므로, 쪽 이미지를 만들어 직접 본다.

```powershell
python -c "
from pyhwpx import Hwp
h=Hwp(new=True,visible=False)
h.open(r'<결과.hwp 전체 경로>')
print('pages', h.PageCount)
h.create_page_image(r'<임시폴더>\p.png', pgno=-1, resolution=80)
h.quit()
"
```

- 생성된 `p001.png`, `p002.png` … 를 열어 확인한다. 임시 폴더는 세션의 scratchpad를 쓴다.
- 쪽수가 요청 분량을 넘으면 원고를 줄여 다시 변환한다.
- 서식 자체를 바꾸려면 `scripts/md2hwp.py` 위쪽의 디자인 설정을 고친다.
  예: 주 색상 `MAIN`, 글꼴 `FONT_HEAD`/`FONT_BODY`, 여백 `MARGIN_SIDE`.

## 6. 완료 안내

사용자는 교사이며 코딩 용어에 익숙하지 않을 수 있다. 쉬운 말로 다음을 알려 준다.
- 만든 파일(.hwp, .pdf, 원고 .md)의 위치 링크와 쪽수
- 문서 구성 요약 (장 목록을 짧은 표로)
- 직접 채우거나 고쳐야 할 부분 (`○○` 자리, 예시 수치·예산)
- 수정 방법: 한글에서 직접 고치거나, 원고 .md를 고친 뒤 같은 명령으로 다시 변환

## 참고: 스크립트 사용법 요약

```
python md2hwp.py 입력.md [출력.hwp] [--show] [--pdf]
  --show : 변환 후 한글 창을 띄워 둔다
  --pdf  : PDF도 함께 저장한다
```
