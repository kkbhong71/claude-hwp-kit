# 클로드로 한글(HWP) 업무 문서 만들기 초보자 가이드

## 1. 이 키트로 할 수 있는 일

- Claude에게 "○○ 계획서를 한글 문서로 만들어 줘"라고 말하면, 내용 작성부터 한글(.hwp) 파일 저장까지 한 번에 처리된다.
- 남색 제목 상자, 번호가 붙은 장 제목 띠, 색이 들어간 표 등으로 꾸며진 문서가 만들어진다.
- 같은 내용의 PDF도 함께 만들어져 결재·공유용으로 바로 쓸 수 있다.
- "5쪽 이내", "표 포함", "예산 1,000만 원 기준" 같은 조건을 말하면 그대로 반영한다.

### 1.1 어떻게 동작하나요?

| 단계 | 하는 일 | 누가 |
|---|---|---|
| 1 | 요청 내용을 바탕으로 문서 원고 작성 | Claude |
| 2 | 원고를 꾸민 한글 문서로 변환 | 내 PC의 한글 프로그램 (자동 조작) |
| 3 | 쪽수와 모양을 확인하고 필요하면 수정 | Claude |
| 4 | 완성 파일 위치와 고칠 부분 안내 | Claude |

> 한글 프로그램을 직접 조작하는 방식이므로, 한글이 설치된 Windows PC에서만 사용할 수 있음.

## 2. 준비물 확인

| 준비물 | 확인 방법 | 비고 |
|---|---|---|
| Windows 10 또는 11 PC | 대부분의 학교 PC 해당 | Mac은 사용 불가 |
| 한컴오피스 한글 | 시작 메뉴에서 '한글' 검색 | 학교 PC에는 대부분 설치됨 |
| Claude 유료 요금제 | claude.ai 접속 후 설정에서 요금제 확인 | Pro 이상 필요 (Code 탭 사용) |
| Claude 데스크톱 앱 | 시작 메뉴에서 'Claude' 검색 | 꼭 앱이어야 함 (웹 브라우저 불가), 없으면 claude.ai/download 에서 설치 |
| Python | 설치 프로그램이 자동 확인 | 없으면 설치 중 자동 설치 가능 |

### 2.1 꼭 확인: 웹 브라우저가 아니라 데스크톱 앱에서 써야 한다

- 크롬·엣지에서 claude.ai 에 접속해 쓰는 Claude(웹)는 인터넷 서버에서 동작한다. 그래서 내 PC에 설치된 한글 프로그램을 쓸 수 없다.
- 반드시 내 PC에 설치하는 Claude 데스크톱 앱의 Code 화면에서, 환경을 '로컬'로 골라야 한다.
- 웹에서 Code를 열면 환경 목록의 '로컬' 옆에 '다운로드 · 데스크톱 앱 전용'이라고 표시된다. 이 표시가 보이면 지금 웹 브라우저를 쓰고 있는 것이다.

| 구분 | 웹 브라우저 (claude.ai) | 데스크톱 앱 |
|---|---|---|
| 실행 위치 | 인터넷 서버 (클라우드) | 내 PC (로컬) |
| 한글 문서(.hwp) 만들기 | 불가 | 가능 |
| 주소창 | 있음 (claude.ai/code) | 없음 (별도 프로그램 창) |
| 설치 | 필요 없음 | claude.ai/download 에서 설치 |

### 2.2 Windows MCP를 따로 설치해야 하나요?

- 설치하지 않아도 된다. Claude 데스크톱 앱의 Code 탭은 내 PC에서 직접 프로그램을 실행할 수 있어서, 별도의 MCP 없이도 한글을 조작할 수 있다.
- MCP는 Chat 탭에서 PC를 조작하고 싶을 때 쓰는 연결 방식인데, 설정 파일을 직접 고쳐야 해서 초보자에게 어렵고 이 키트에는 필요하지 않다.
- 따라서 이 가이드는 가장 간단한 방법인 Code 탭 + 스킬 방식으로 안내한다.

## 3. 키트 내려받기

세 가지 방법 중 편한 것 하나만 고르면 된다.

### 3.1 방법 A: 파일(ZIP)로 받기

1. 메신저·메일·학교 공유 폴더 등으로 받은 claude-hwp-kit.zip 파일을 저장한다.
2. ZIP 파일을 마우스 오른쪽 버튼으로 누르고 '압축 풀기' 또는 '모두 압축 풀기'를 선택한다.
3. 압축을 푼 claude-hwp-kit 폴더를 연다.

### 3.2 방법 B: GitHub에서 받기

1. 안내받은 GitHub 주소(예: github.com/kkbhong71/claude-hwp-kit)에 접속한다.
2. 오른쪽 위의 초록색 'Code' 버튼을 누른다.
3. 맨 아래 'Download ZIP'을 누른다.
4. 내려받은 ZIP 파일의 압축을 풀고 폴더를 연다. (폴더 이름 끝에 -main 이 붙어 있어도 괜찮다.)

### 3.3 방법 C: Claude에게 설치까지 맡기기 (가장 쉬움)

1. Claude 데스크톱 앱(웹 브라우저 아님)을 열고 Code 화면에서 환경을 '로컬'로 고른다.
2. 아래 문장을 그대로 입력한다. (주소는 안내받은 GitHub 주소로 바꾼다.)
3. Claude가 키트를 내려받고 설치까지 진행한다. 중간에 허용 여부를 물으면 내용을 읽어 보고 '허용'을 누른다.

> 입력 예시: "github.com/kkbhong71/claude-hwp-kit 키트를 내려받아서 install.ps1로 설치해 줘"

## 4. 설치하기 (방법 A·B를 고른 경우)

1. 압축을 푼 폴더에서 '설치하기.bat' 파일을 더블클릭한다.
2. 보안 경고 창이 뜨면 실행을 허용한다. 'Windows의 PC 보호' 파란 창이면 '추가 정보' → '실행', '게시자를 확인할 수 없습니다' 창이면 '실행'을 누른다.
3. 검은 설치 창이 열리고 6단계가 차례로 진행된다. 각 단계에 초록색 OK가 표시되면 정상이다.
4. Python이 없으면 자동 설치 여부를 묻는다. Y를 입력하고 Enter를 누른다.
5. 마지막에 '설치가 끝났습니다!'가 나오면 아무 키나 눌러 창을 닫는다.

### 4.1 설치가 끝나면 생기는 것

| 항목 | 위치 | 설명 |
|---|---|---|
| Claude 스킬 | 사용자 폴더\.claude\skills\school-hwp-docs | Claude가 한글 문서 만드는 방법을 익힌 설명서 |
| 작업 폴더 | 문서\HWP자동화 | 만든 문서가 저장되는 곳 |
| 바탕 화면 바로가기 | 바탕 화면\HWP자동화 폴더 | 작업 폴더를 바로 여는 아이콘 |
| 설치 확인 문서 | 문서\HWP자동화\설치확인.hwp | 열어서 꾸며진 문서가 보이면 성공 |

### 4.2 (선택) Claude 앱 목록에 스킬 등록하기

- 설치 프로그램이 이미 스킬을 넣어 두었으므로 이 단계는 하지 않아도 된다.
- Claude 앱의 '사용자 지정' 화면에서 스킬을 확인하거나 켜고 끄고 싶다면, 키트 폴더의 school-hwp-docs.skill 파일을 올린다.
- 방법: 왼쪽 메뉴 '사용자 지정' → 'Skills' → 오른쪽 위 '+ 추가' → 파일 업로드 → school-hwp-docs.skill 선택
- 등록되면 '내 항목' 탭의 '내가 만듦'에 school-hwp-docs가 보인다.

## 5. 문서 만들기

### 5.1 처음 한 번만 하는 설정

1. 시작 메뉴에서 'Claude'를 검색해 데스크톱 앱을 연다. (크롬·엣지에서 claude.ai 를 여는 것이 아니다.)
2. 왼쪽 위의 '</>' 아이콘(Code)을 눌러 Code 화면으로 이동한다.
3. '새로 만들기'를 누르고, 입력창 아래의 환경을 '로컬'로 고른다. ('클라우드'나 '자동'이 선택되어 있으면 바꾼다.)
4. 폴더 선택 화면이 나오면 '문서' 안의 'HWP자동화' 폴더를 고른다.
5. 이후에는 같은 방법으로 새 세션을 열면 된다.

> OneDrive 백업이 켜진 PC는 탐색기 주소가 '백업 시작 > 문서 > HWP자동화'처럼 보이는데, 이것도 정상임.

### 5.2 요청하는 방법

- 문서 종류, 학년도, 분량, 꼭 넣을 내용을 함께 말하면 결과가 좋아진다.
- 학교명, 학생 수, 예산처럼 실제 정보를 알려 주면 그대로 들어가고, 알려 주지 않으면 ○○ 자리로 남겨 둔다.
- 결과를 본 뒤 "3장에 표를 하나 더 넣어 줘", "2쪽으로 줄여 줘"처럼 이어서 고쳐 달라고 하면 된다.

| 목적 | 요청 예시 |
|---|---|
| 동아리 계획서 | 2027학년도 과학 탐구 동아리 운영 계획서를 3쪽 이내 한글 문서로 만들어 줘 |
| 교과 운영 방안 | 중학교 수학 기초학력 보장 운영 방안을 8쪽 이내로 구체적으로 작성해 줘 |
| 행사 계획 | 학교 축제 운영 계획을 일정표와 역할 분담표를 넣어서 한글 문서로 만들어 줘 |
| 결과 보고서 | 첨부한 메모를 바탕으로 2학기 방과후학교 운영 결과 보고서를 만들어 줘 |
| 수정 요청 | 방금 만든 문서에서 예산 합계를 500만 원으로 맞추고 다시 만들어 줘 |

### 5.3 결과물 확인과 수정

- 완성되면 Claude가 .hwp, .pdf, 원고(.md) 파일의 위치를 알려 준다. 바탕 화면의 'HWP자동화 폴더' 아이콘으로도 열 수 있다.
- 간단한 수정은 한글에서 파일을 열어 직접 고치는 것이 가장 빠르다.
- 내용을 크게 바꿀 때는 Claude에게 말로 요청하면 원고를 고쳐 다시 만들어 준다.
- 문서마다 ○○ 표시와 예시 수치는 반드시 학교 실정에 맞게 바꾼 뒤 사용한다.

## 6. 디자인 바꾸기

- 색, 글꼴, 여백은 Claude에게 말로 요청하면 바꿔 준다.
- 예: "문서 주 색상을 초록색으로 바꿔 줘", "본문 글꼴을 맑은 고딕으로 바꿔 줘", "표 글씨를 조금 크게 해 줘"
- 바뀐 디자인은 이후 만드는 모든 문서에 똑같이 적용된다.

| 꾸밈 요소 | 기본 모양 | 바꿀 수 있는 것 |
|---|---|---|
| 문서 제목 | 남색 상자, 흰 글씨 | 색, 글자 크기 |
| 장 제목 | 남색 번호 칸 + 연한 파란 띠 | 색, 글꼴 |
| 글머리표 | ○ 기호, 내어쓰기 | 기호 모양 |
| 표 | 남색 머리행, 줄무늬, 합계 행 강조 | 색, 글자 크기 |
| 쪽 번호 | 아래 가운데 (- 1 -) | 위치 |

## 7. 문제 해결

| 증상 | 원인 | 해결 방법 |
|---|---|---|
| 설치 창에 '한글이 설치되어 있지 않습니다' | 한컴오피스 한글 미설치 | 한글을 설치한 뒤 설치하기.bat 다시 실행 |
| 'Python을 설치했지만 인식되지 않습니다' | 설치 직후 경로 반영 전 | PC를 다시 시작하고 설치하기.bat 다시 실행 |
| 부품 설치 실패 | 학교망 방화벽, 인터넷 연결 | 다른 네트워크에서 설치하거나 정보 담당자에게 문의 |
| 한글 '보안 승인' 창이 뜸 | 프로그램이 한글 파일에 접근 | '모두 허용' 선택 |
| 환경 목록에 '로컬 · 다운로드 · 데스크톱 앱 전용'이 보임 | 웹 브라우저(claude.ai)에서 접속함 | Claude 데스크톱 앱을 설치해 그 앱에서 다시 시작 |
| 내 PC 폴더를 고르는 화면이 안 나옴 | 환경이 '클라우드'나 '자동'으로 되어 있음 | 데스크톱 앱에서 환경을 '로컬'로 변경 |
| Claude가 한글 문서를 안 만들고 글로만 답함 | Chat 탭에서 요청함 | Code 탭에서 다시 요청 |
| 스킬을 쓰지 않는 것 같음 | 요청에 문서 형식이 불분명 | 요청 끝에 'school-hwp-docs 스킬로 한글 문서로'를 덧붙임 |
| 만든 파일이 탐색기에서 안 보임 | 다른 폴더를 보고 있음 | 바탕 화면의 'HWP자동화 폴더' 아이콘으로 열기 |
| 변환 중 멈춘 것 같음 | 한글이 뒤에서 작업 중 | 1~3분 기다리기, 계속 멈추면 작업 관리자에서 한글 종료 후 다시 요청 |

> 해결되지 않으면 오류 화면을 캡처해 Claude Code에 붙여 넣고 "이 오류 해결해 줘"라고 요청하면 대부분 바로 해결됨.

## 8. 사용 시 유의 사항

- Claude가 쓴 내용은 초안이다. 법령·지침명, 날짜, 수치는 반드시 담당자가 최신 자료와 대조해 확인한다.
- 학생 이름, 연락처, 성적 등 개인정보는 요청 내용에 넣지 않는다. 필요하면 ○○○ 등으로 바꿔 요청한 뒤 문서에서 직접 채운다.
- 학교·교육청의 생성형 AI 활용 지침이 있다면 그 지침을 우선 따른다.
- 이 키트는 개인이 만든 도구이며, 한글과컴퓨터 및 Anthropic의 공식 제품이 아니다.
